## 🚀 Overview
Predict maize crop yields in Rwanda using machine learning to help farmers and policymakers make data-driven decisions.

## 📊 Features
- Climate data integration (rainfall, temperature)
- Soil quality analysis
- Historical yield prediction
- Interactive visualizations

## 🛠️ Tech Stack
- **Python** - Core logic
- **Scikit-learn** - ML models
- **Pandas/NumPy** - Data processing
- **Matplotlib** - Visualizations

## 📈 Model Performance
| Model | Accuracy | RMSE |
|-------|----------|------|
| Random Forest | 89% | 0.12 |
| XGBoost | 91% | 0.10 |
